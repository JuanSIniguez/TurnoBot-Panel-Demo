# TurnoBot · prototipo de panel

Prototipo público y navegable de un panel para gestionar reservas de un negocio. La agenda permite consultar a todos los profesionales a la vez, filtrar por persona y alternar entre día y semana. También incluye vistas de solicitudes de cambios, servicios y profesionales.

## Probar localmente

Abrí `index.html` en un navegador. El sitio usa HTML, CSS y JavaScript sin instalación ni compilación.

## Publicar con GitHub Pages

En el repositorio de GitHub, abrí **Settings → Pages → Build and deployment**. Elegí **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guardá y consultá en esa misma pantalla la URL publicada.

## Alcance de esta versión

- Los nombres, servicios, horarios y reservas son ficticios.
- Las reservas agregadas al calendario existen solo en la memoria del navegador durante la visita. El formulario hace una comprobación básica de cupo y compatibilidad, sin un motor de disponibilidad completo.
- Las solicitudes muestran el impacto posible, pero no aplican cambios.
- No hay cuentas de usuario, datos reales ni integración con WhatsApp.

Este repositorio contiene únicamente la maqueta pública. Las especificaciones de producto y el desarrollo funcional se administran por separado.
